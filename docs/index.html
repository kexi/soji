soji

開発者マシンのディスクを、理由を示して掃除する。

71.4 GB 開発から 2 年経ったマシンで実際に見つかったキャッシュの量

ダウンロード GitHub

macOS 26 以降 / Apple Silicon

消していいものだけを消す

対象は開発ツールが自分で作り直せるものだけです。ソースコードや設定、 あなたが手で置いたファイルには一切触れません。

安全

再生成できる

Homebrew のボトル、npm・Cargo・Gradle のキャッシュ、Xcode の DerivedData。次のビルドやインストールで自動的に戻ります。

再取得が重い

戻せるが時間がかかる

Maven のローカルリポジトリ、Go のモジュールキャッシュ、実機の DeviceSupport。消せますが、取り直しにネットワークと時間が要ります。

要確認

ツールに任せる

Docker の仮想ディスクや Go のモジュール本体は直接消すと壊れます。soji は消さず、docker system prune のような正しいコマンドを提示します。

ゴミ箱には入れません

ゴミ箱への移動は同じディスク上での名前の付け替えにすぎず、空き容量は 1 バイトも増えません。 soji は完全に削除します。だからこそ対象を再生成できるものに絞っています。

0.024 秒 20,000 ファイルをゴミ箱に移動した時間。空き容量の増加は 0 バイト。
1.4 秒 同じファイルを実際に削除した時間。この 60 倍の差が「何も解放していない」ことの証拠です。
概算 APFS のファイル複製は du でさえ二重に数えます。soji は削除後に実際の解放量も示します。

まず見せる。消すのはそのあと

起動するとスキャンが走り、何がどれだけあるかを一覧にします。 各項目には「なぜ消して安全か」と「消えると何が起きるか」が付きます。 削除は選んで明示的に実行したときだけです。

コマンドラインでも同じことができる

GUI でできることは CLI でもできます。AI エージェントから使えるよう、 構造化された JSON を返し、削除は明示しない限り実行しません。 

# 候補を JSON で得る（何も消さない）
soji scan --json

# 何が消えるかを確認する（既定はドライラン）
soji clean

# 実際に削除する
soji clean --yes

# 何を消すと何が起きるかを読む
soji rules --json

clean は --yes を付けない限り 1 バイトも削除しません。
